Feature map

The full RUN4 system at a glance.

The app is organized around four tracks, per-track devices, performance sets, live modulation, external plugin hosting, and export-ready project persistence.

Tape mode

  • Record, overdub, loop regions, waveform display, and tape gain.
  • Always-listening internal Capture turns the last 4-16 seconds of RUN4 into a new tape take.
  • Freeze/Hold parks the tape moment without rewriting the buffer.
  • Play All / Stop All performance transport across four tapes.
  • Time/pitch decoupling, keylock counter-compensation, scale-aware pitch context.
  • Tape Bloom with six read heads, warble, degrade, and stereo motion.
  • Shadow: one hidden, deterministic companion playhead with bounded drift, level compensation, and project-recalled character.
  • Memory capture and recall, including playable reverse, pitch, and tempo variations.
  • Command Sequencer with jumps, stutters, holds, gates, nudge, memory steps, probability, and pattern chains.

Poly mode

  • Poly Sample playback with lazy voice allocation.
  • Classic and four-operator FM synth engines with factory and user presets.
  • Four FM routings: Stack, Branch, Dual, and Cross; each with per-operator ratio, level, and decay.
  • Built-in pattern sequencer: 1-64 steps, live keyboard step entry, chords, eight sample-kit slots, and per-step velocity, gate, chance, and nudge.
  • Pattern Tools for transforms, Euclidean fills with instant Randomize, and one-step Undo.
  • Humanize adds restrained velocity and micro-timing drift; performance randomizer changes velocity, gate, chance, or all three lanes.
  • Kit presets store and recall the eight sound slots independently of the pattern.
  • AUv3 instrument hosting with discovery, load, editor, persistence, and robust restore.
  • Per-track MIDI channel assignment for four independent tracks.

Disc mode

  • Long-form disc streaming source for material playback.
  • Works as a source into the same device chain as Tape and Poly.
  • Linked file and folder workflows keep large media referenced cleanly.

Devices

  • Grain engine with lock-free parameter snapshots.
  • Grain Freeze captures the current grain buffer for continued scanning, pitch, spray, and modulation.
  • Tone: lowpass, highpass, bandpass, formant, resonator, and DJ curve.
  • Color: saturation, folding, bit reduction, ring modulation, and tone shaping.
  • Air: rooms, halls, plates, wide spaces, delays, freeze, tone, and damping.

Performance

  • Up to 128 sets per project with Store, Recall, and Store to Next.
  • Performance Pad maps expressive X/Y motion onto selected track and device parameters.
  • Eight macros per tape bank, four macro banks per project.
  • Macro values are stored per set; macro mappings connect to existing parameters.
  • Punch-In FX with hold, release reset, multi-touch, and global performance row.

Modulation

  • Four modulators per track at 30 Hz control rate.
  • LFO, envelope, random, follow-style, and self-listening modulation.
  • Targets include Material, Devices, Mixer, Master, and Sends.
  • Parameter bars show modulation markers and live value movement.

Mixer and FX

  • Four track mixer with level, sends, DJ filter, and master path.
  • Four fixed Send Busses A-D with one AUv3 FX slot each.
  • Master AUv3 FX chain with two slots before master dynamics and export.
  • Final master chain: Tone → Drive → Glue → OTT → Width → brick-wall Limiter.
  • Clarity Analyze suggests a starting preset; live gain-reduction feedback appears on Glue, OTT, and Limit.
  • Mastering presets: Neutral, Gentle Glue, Open Highs, Ambient, and Warm Tape.
  • Plugin load, remove, bypass, editor presentation, and state persistence.
  • Dirty-state handling avoids unnecessary plugin reads on tab changes.

Project and sample store

  • Project persistence for sets, tracks, poly state, FX chains, AUv3 state, modulation, macros, and punch-ins.
  • Opt-in iCloud project sync packages the project with its used audio, so it can continue between iPhone and iPad.
  • Conflict-safe cloud handling keeps the local project intact and asks you to open the newest version before overwriting.
  • Security-scoped linked file and folder support.
  • Sample Browser lists recordings, recent imports, and linked folder trees.
  • Swipe delete for recordings, remove for imports, and unlink for folders; project library updates and autosaves.
  • Recent imports and bounded external buffer cache for faster session workflows.

Export

  • Live export of master and track stems as WAV.
  • Offline bounce for tape loops, master output, and stems faster than realtime.
  • Designed around project recall and performance capture.

Recording and metronome

  • Free or fixed 1/2/4/8-bar Tape and Poly captures with Record or Record & Play.
  • Independent one-bar Count-in shows a clear four-beat preparation before recording.
  • Metronome offers adjustable level and Always, Rec, Play, or Rec + Play activity modes.
